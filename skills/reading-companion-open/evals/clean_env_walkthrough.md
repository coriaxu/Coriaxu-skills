# 干净环境验收清单

发布前必须在一个没有任何已有笔记库的环境（如新建空目录、另一台电脑、新用户账户）从零跑通以下全流程。任何一步失败即不可发布。

## 前置

- [ ] 测试目录为空，不存在 `reading-companion.config.md`
- [ ] skill 已安装到目标工具的 skills 目录

## 第一段：Onboarding

1. [ ] 说「读书陪读」，skill 激活且只问两个问题（路径、是否 Obsidian）
2. [ ] 回答后自动建成：笔记库根目录、`00-当前加工书架.md`（含占位文本）、`reading-companion.config.md`（字段完整、默认值正确）
3. [ ] AI 报告了建好的结构，并问「这次想读哪本书？」
4. [ ] 手动制造一个缺少 `library.root` 的坏配置，再次激活时 AI 指出缺失字段，没有猜路径或写文件
5. [ ] 手动制造两个配置文件，再次激活时 AI 列出路径并要求选择一个，没有合并两个笔记库

## 第二段：新书陪读与首次存档

6. [ ] 给出书名后进入新书开读，不建任何书目录（验证「第一次存档前不建目录」）
7. [ ] 发一段原文 + 一句感想，AI 只围绕该段讨论，没有吞整本书
8. [ ] 说「存档」，AI 展示完整卡片预览后停下等确认，没有直接写文件
9. [ ] 预览后只回复「嗯」，AI 没有写文件，而是继续等待明确确认
10. [ ] 确认后检查磁盘：书文件夹、索引页 `00-Index-书名.md`、卡片文件全部生成；索引页「卡片目录」「下次继续」已填；书架「加工中」出现该书条目
11. [ ] 卡片内容核对：作者原文一字未改；用户感想完整保留且不含操作指令（「存档」这句没被收进卡）；AI 延伸单独成层
12. [ ] 再次保存同标题卡片时，AI 没有覆盖旧文件，而是询问续写、改名或另存

## 第三段：接续与回炉

13. [ ] 关闭对话，新开一个对话说「开启陪读」，AI 正确读出书架并提议继续这本书
14. [ ] 发一条「旧笔记」（可现编一条标注为三年前的笔记），AI 走回炉流程；存档时使用回炉卡模板，「我之前的笔记」与「我今天的追问与讨论」分区存放

## 第四段：结读与边界

15. [ ] 说「换一本」，AI 先询问当前书是否暂停或结读，没有把两本书混在同一套卡片里
16. [ ] 说「结读」，索引页 status 变 complete，书架条目移入「最近完成」且带卡片计数，「加工中」恢复占位文本
17. [ ] 对话中故意聊起第二本书，AI 提醒另开对话
18. [ ] 模拟无文件权限环境（或口头声明「这个环境不能写文件」），AI 切换 draft-only 输出完整文件内容
19. [ ] 在非读书上下文只说「存档」，skill 不激活

## 第五段：残留扫描

20. [ ] 对整个 skill 目录执行残留检查，以下关键词零命中（开发者私人信息不得进入开源包；本验收文件自身排除）：

```bash
grep -rn --exclude='clean_env_walkthrough.md' "surfin\|徐老师\|小萌\|正言\|若谷\|Vera\|虾哥\|coriaxu985\|20-知识库\|flomo-processor\|reading-notes-splitter\|xray-book\|study-coach" reading-companion-open/
```

预期输出为空（本文件自身除外）。
